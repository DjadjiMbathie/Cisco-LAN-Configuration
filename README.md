# Cisco Packet Tracer – Configuration d'un LAN

## 🎯 Objectif

Mettre en place et configurer un réseau local (LAN) composé de
4 ordinateurs et d'une imprimante dans Cisco Packet Tracer.

## 🌐 Plan d'adressage

- Réseau : 192.168.1.0/24
- Masque : 255.255.255.0

| Équipement | Adresse IP |
|---|---|
| PC1 | 192.168.1.1 |
| PC2 | 192.168.1.2 |
| PC3 | 192.168.1.3 |
| PC4 | 192.168.1.4 |
| Imprimante | 192.168.1.5 |

## 🧪 Tests

Des tests `ping` ont été réalisés entre les différents équipements
afin de vérifier la connectivité du réseau.

## 🛠️ Outil utilisé

- Cisco Packet Tracer
